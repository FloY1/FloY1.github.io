# Инструкции для агентов

## Назначение проекта

Проект - автономное мобильное веб-приложение "Эхолот" для сохранения рыболовных мест, промеров глубины и параметров катушки. Интерфейс и пользовательские сообщения написаны на русском языке. Приложение работает без сервера и хранит данные локально в браузере.

## Структура

Весь код находится в `index.html`:

- `<style>` содержит тему, адаптивную верстку и состояния компонентов.
- Разметка `<body>` содержит общую оболочку, боковое меню, модальное окно и уведомления.
- `<script>` содержит модель данных, хранение, навигацию, рендеринг экранов, обработчики, расчеты катушки и отрисовку `canvas`.

Не добавляйте сборщик, фреймворк, пакетный менеджер или внешние зависимости без прямого требования. Для текущего масштаба предпочтительно сохранять автономный однофайловый формат.

## Запуск

Сборка и установка зависимостей не нужны. Запускайте локальный HTTP-сервер из корня проекта:

```bash
python3 -m http.server 8000
```

Открывайте `http://localhost:8000/`. Используйте HTTP-сервер, а не `file://`: так поведение браузерных API ближе к реальной эксплуатации.

## Архитектура приложения

- `DB` - единое изменяемое состояние приложения: места, лучи промеров, катушка, пресеты и настройки графиков.
- Основное хранилище - `localStorage` с ключом `fishmap.db.v1`; при его отсутствии используется `window.storage`.
- `load()` загружает данные, `normalizeDB()` нормализует старые структуры, `save()` сохраняет состояние с задержкой.
- `route` задает текущий экран. `go()` меняет маршрут, `render()` создает разметку и подключает обработчики.
- Функции `view...()` должны только формировать HTML. Соответствующие `after...()` подключают поведение после вставки разметки.
- `viewCleanup` освобождает глобальные обработчики текущего экрана перед повторным рендерингом.
- Графики и карта дна рисуются через Canvas API.
- Экспорт и импорт используют JSON. `validImport()` является границей доверия для загружаемых файлов.

## Правила изменений

- Сохраняйте мобильный подход, ширину основного контента до 600 px, safe-area отступы и поддержку `prefers-reduced-motion`.
- Используйте существующие CSS-переменные темы и классы компонентов. Не создавайте вторую дизайн-систему.
- Пользовательский текст пишите на русском языке. Имена JavaScript-символов и технические идентификаторы - на английском.
- Любые пользовательские значения, вставляемые в HTML-строки, пропускайте через `esc()`. Для простого текста предпочитайте `textContent`.
- После изменения `DB` вызывайте `save()`. Если изменение должно быть видно сразу, затем вызывайте `render()` или переходите через `go()`.
- При изменении схемы данных обновляйте одновременно значения по умолчанию, `normalizeDB()`, импорт, экспорт и все места чтения данных. Старые сохранения должны продолжать загружаться.
- Не ослабляйте `validImport()`. Новые импортируемые поля должны проверяться до присваивания в `DB`.
- Не оставляйте глобальные обработчики и анимационные кадры после ухода с экрана. Освобождайте их через `viewCleanup`.
- Не встраивайте непроверенные данные в селекторы, атрибуты, SVG или Canvas-подписи.
- Не меняйте формулы катушки без проверки прямого и обратного преобразований `metersToTurns()` и `turnsToMeters()` на граничных значениях.
- Сохраняйте автономную работу: новые основные сценарии не должны требовать сети.

## Проверка

Автоматических тестов, линтера и сборки сейчас нет. После каждого изменения выполните целевой ручной smoke-тест в браузере.

Минимальная проверка общих изменений:

1. Открыть приложение без ошибок в консоли.
2. Создать место и луч промеров, добавить не менее двух промеров.
3. Открыть профиль и карту дна, изменить масштаб и единицы измерения.
4. Перезагрузить страницу и убедиться, что данные сохранились.
5. Экспортировать JSON, удалить или изменить данные, затем импортировать файл обратно.
6. Проверить узкий мобильный viewport и обычный настольный viewport.

Для локальных изменений проверяйте только затронутый сценарий и связанные границы. Для изменений хранения или схемы данных дополнительно проверяйте пустое хранилище, существующее хранилище и некорректный импорт.
