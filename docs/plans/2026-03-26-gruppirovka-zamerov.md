# План: группировка и усреднение замеров

Статус: реализовано.

Связано: `CONTEXT.md`, ADR `docs/adr/0001-gruppirovka-i-usrednenie-zamerov.md`.

## Зачем

На одной и той же дистанции (одинаковые обороты) повторные забросы дают разброс счёта на 2–4. Карта шумит, список разрастается. Нужно сгладить отображение, не теряя сырые данные до явного решения рыбака.

## Решения

### 1. Ключ группы

- Группа = замеры **одного луча** с **точным** совпадением оборотов.
- Допуск (±1 и т.п.) не вводим.

### 2. Два слоя: представление и данные

| Слой | Поведение |
|------|-----------|
| **Группировка / усреднение** | Только вид. Данные в хранилище не меняет. |
| **Объединение группы** | Явное действие. N замеров → 1. Сырые удаляются. Без авто-merge. |

### 3. Точка на картах (проекция группы)

Где: **профиль дна**, **вид сверху**, **sparkline**.

| Поле | Правило |
|------|---------|
| Обороты | Ключ группы |
| Счёт | Среднее арифметическое, округление до **шага 0.5** |
| Дно | Большинство среди **заполненных**; пустые не голосуют; ничья → более новый замер |
| Метка | То же, что дно |
| N = 1 | Точка = сам замер (как сейчас) |

### 4. Список замеров на экране луча

| N | UI |
|---|-----|
| 1 | Одна строка, как сейчас |
| ≥ 2 | **Свёрнутая** карточка-группа |

Шапка группы:

- обороты;
- средний счёт (шаг 0.5);
- бейдж `×N`;
- разброс счёта (min–max);
- кнопка **«Объединить»**.

Раскрытие (тап по шапке / явному контролу):

- сырые замеры с текущими действиями: edit, delete, clip.

### 5. Объединение группы

Только по кнопке. Перед заменой — короткий confirm (действие необратимо).

Итоговый замер:

| Поле | Правило |
|------|---------|
| Обороты | Как у группы |
| Счёт | Среднее, шаг 0.5 |
| Дно / метка | Как у точки профиля |
| Клипса | OR: true, если была хотя бы у одного |
| Заметки | Непустые, склеить через `; `, без дублей |
| id | Новый |

После объединения в хранилище остаётся один замер; группа N≥2 исчезает, пока снова не появятся совпадающие обороты.

### 6. Вне скоупа (сейчас не делаем)

- Допуск/бакеты по оборотам.
- Авто-merge при записи или по таймеру.
- Хранение истории сырых после объединения.
- Флаг «не участвовать в среднем» на замере.
- Медиана / «только последний» вместо среднего.
- Отдельная сущность «станция» в модели данных.

## Затронутое поведение (верхний уровень)

1. **Профиль / вид сверху / sparkline** — одна точка на уникальные обороты, без «дрожания» счёта.
2. **Список луча** — визуальные группы + раскрытие + «Объединить».
3. **Хранилище** — меняется только при объединении (и при обычном CRUD замеров как сейчас).
4. **Импорт/экспорт** — формат JSON без изменений; группы считаются на лету.

## Критерии готовности (продукт)

- Два+ замера с одинаковыми оборотами: на всех картах одна точка со средним счётом (шаг 0.5).
- В списке они в одной свёрнутой группе с `×N` и разбросом.
- «Объединить» после confirm оставляет один замер с согласованными полями.
- Без кнопки «Объединить» число сырых замеров в данных не уменьшается.
- Замеры с разными оборотами ведут себя как раньше.

## Открытых продуктовых вопросов нет

«Новее» при ничьей: более поздний замер в данных луча (создание по времени / порядок в массиве).
