# Батиметрия берётся из Deeper и лежит в пакете вектором

Источник батиметрии - Deeper (fishdeeper.com, краудсорсные промеры эхолотов), а не Navionics SonarChart. В пакете водоёма вместо растровых XYZ PNG лежит векторный `bathymetry.json`: полосы глубин (полигоны диапазонов с шагом 33 см, значения в сантиметрах) и подписи глубин по уровням зума. Приложение рисует полосы штатным Leaflet (canvas, заливка без обводки), подписи - набором для текущего зума. Растровые пакеты прежнего формата приложение продолжает читать; сборщик их больше не производит.

Причины:

- На малых водоёмах (Горново) Navionics пуст, а у Deeper есть реальные промеры; замер покрытия показал данные Deeper на всех трёх боевых пакетах вдоль воды.
- Deeper - реальные треки эхолотов, а не интерполяция; шаг полос 33 см тоньше изобат SonarChart.
- Вектор снимает ограничения растра: карта чёткая на любом зуме без пирамиды тайлов, глубина становится числом в данных (палитра и стиль - обратимые решения кода, а не запечённые пиксели). Вес пакета сопоставим с растровым (0.6-2.7 МБ на боевых пакетах; основной вклад - дубли вершин на швах z18-нарезки и подписи семи уровней).

Ключевые параметры пайплайна (проверено экспериментально 2026-08-11):

- Тайлы `https://c-triton.fishdeeper.com/web/v1/tile/global/{x}/{y}/{z}.vector` - Mapbox Vector Tile v2, слои `depth` (полигоны, см) и `depth_labels` (точки, подписи в м/фатомах/футах). Нужен только `token` из сессии maps.fishdeeper.com; `tileToken` не требуется. `z19` отвечает 404.
- Геометрия почти не зависит от зума: на одной области z16/z17/z18 дали 699/914/986 вершин при идентичных наборах полос; прирост - в основном дубли на швах нарезки. Геометрия берётся с z18 (родной максимум, решение пользователя «брать всё»), подписи - со всех уровней z12-z18, потому что источник расставляет их с плотностью под каждый зум.
- Полигоны разных тайлов не объединяются: полосы рисуются заливкой без обводки, швы невидимы. Линии-изобаты потребовали бы robust polygon union без зависимостей - отклонено как несоразмерная сложность; стиль обратим, пакет менять не придётся.

## Последствия

- Частично отменяет [ADR-0002](0002-vneshnyaya-batimetriya-na-etape-razrabotki.md): источник теперь Deeper, но принцип прежний - батиметрия готовится на этапе разработки, приложение в сеть не ходит.
- [ADR-0009](0009-piramida-zumov-v-pakete.md) неприменим к векторным пакетам: памяти под пирамиду битмапов нет, зум свободен (minZoom вычисляется по «водоём влезает в экран», maxZoom = 22). Для оставшихся растровых пакетов ADR-0009 в силе.
- Из сборщика удалены Navionics-загрузчик и команда `pyramid`; `demo-lake` остаётся растровым как проверка обратной совместимости и путь отката.
- Токен Deeper добывается вручную из devtools maps.fishdeeper.com; срок жизни неизвестен. Сервер Deeper генерирует тайлы на лету и часто отвечает 504 - сборщик обязан ретраить с бэкоффом, полная выкачка z12-z18 трёх пакетов занимает часы и кэшируется в `.deeper-cache/`.
- Покрытие Deeper краудсорсное: внутри тайла с данными промерена может быть только полоса трека. Пустое покрытие не блокирует пакет - он собирается с границей OSM и пустой батиметрией.
- Перераспространение данных Deeper - тот же осознанно принятый ToS-риск, что и в [ADR-0005](0005-publikaciya-paketov-vodoemov.md) для Navionics.
