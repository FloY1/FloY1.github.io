# Вендоренный Leaflet и PWA вместо строгого single-file

Георефкарту рисуем локально вендоренным Leaflet (растровые тайлы - ровно наш случай), а приложение превращаем в PWA с service worker, который прекэширует оболочку `index.html`, файлы Leaflet и тайлы/границы водоёмов. Причина: писать собственный slippy-map поверх Canvas дорого и неоправданно, а Leaflet - готовое, крошечное, растровое и тривиально вендорится для офлайна; service worker - единственный честный способ «поставил на телефон и работает без сети».

## Последствия

- Осознанное отклонение от правил `AGENT.md`: приложение перестаёт быть строго однофайловым и получает внешнюю зависимость (вендоренную, без CDN). Отклонение согласовано с владельцем.
- Появляется версионирование кэша service worker при обновлениях и требование HTTPS или localhost для регистрации SW.
- Тайлы и Leaflet вендорятся в репозиторий (никаких сетевых запросов в рантайме).
