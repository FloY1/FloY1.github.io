# Иерархия Водоём -> Место

Вводим верхнеуровневую сущность «Водоём» (озеро, водохранилище или река), внутри которой находятся места ловли; граница и батиметрия привязаны к водоёму, а не к отдельному месту. Причина: карта глубин относится к телу воды целиком, а прежнее «Место» склеивало два разных понятия - водоём и точку ловли.

## Последствия

- Смена схемы `DB`: `places[]` становится вложенным в `waterbodies[]`. Обновляются `normalizeDB()`, импорт, экспорт, `validImport()` и все читатели данных.
- Миграция старых сохранений: существующие плоские места при загрузке оборачиваются в один синтетический водоём «Без привязки» (без геометрии и батиметрии). Старые данные грузятся без потерь; пользователь позже создаёт реальные водоёмы и переносит места.
- v1 поддерживает только замкнутые водоёмы (озеро, водохранилище). Тип «река» зарезервирован в модели, но пакет батиметрии для реки пока не строится.
