# Пакеты водоёмов публикуются вместе с сайтом

Собранные пакеты (`lakes/<slug>/<release>` с тайлами Navionics, `lakes/index.json`, immutable registry и precache) коммитятся в репозиторий и раздаются с GitHub Pages. Причина: приложение офлайн-first и ставится на телефон как PWA; без публикации service worker нечего прекэшировать, и карта дна остаётся только на машине разработчика, то есть теряет весь смысл.

Отменяет решение ADR-0002 «Пакеты не публикуем»; остальная часть ADR-0002 (сборка на этапе разработки, заимствованный Bearer, потолок зума) в силе.

## Последствия

- Тайлы Navionics становятся публично доступны. Это перераспространение чужого платного контента: ToS Navionics/Garmin и копирайт нарушаются, подписка заимствована у by.fishermap.org. Риск принят владельцем осознанно.
- При претензии правообладателя пакеты удаляются из репозитория и истории; готовность к этому - часть решения.
- `attribution` (`© Navionics/Garmin, © OpenStreetMap`) показывается на карте всегда.
- Размер репозитория растёт на каждый водоём (~0.4 МБ на озеро при z18) и на каждый новый release, потому что прежние release остаются на диске для уже открытых клиентов.
