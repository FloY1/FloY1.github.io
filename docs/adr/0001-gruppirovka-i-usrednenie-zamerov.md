# Группировка замеров на одних оборотах и усреднение на карте

Повторные забросы на ту же дистанцию дают разный счёт (на 2–4). Решили: сырые замеры хранить как есть; на картах и sparkline показывать одну точку на точные обороты (среднее счёта); в списке группировать со свёрткой; сливать в один замер только по явной кнопке «Объединить» (необратимо).

Альтернативы отклонены: допуск по оборотам (±N), авто-merge при записи, хранение истории после объединения, медиана вместо среднего.
